# 🚀 Astronauta — Terror, Supervivencia e Infiltración Espacial

> Videojuego de terror y sigilo táctico desarrollado en **Roblox Studio** utilizando **Luau** y sincronizado mediante **Rojo**.

---

## 📖 Sinopsis
Eres un astronauta humano atrapado en una monumental estación espacial alienígena. Para escapar, te disfrazas con un traje y casco alienígena y te haces pasar por un miembro de la tripulación. Deberás explorar sectores generados proceduralmente, gestionar niveles de acceso, esquivar sospechas y encontrar una ruta de evacuación antes de que descubran tu verdadera identidad.

## 🛠️ Tecnologías y Características
- **Generación Procedural DOORS-style:** Mapas 3D con sectores (Dormitorios, Laboratorio, Comedor, Seguridad, Ingeniería, Mando y Cápsulas), llaves-cerraduras y conductos de ventilación alternativos validados matemáticamente.
- **Atmósfera Low-Poly Retro PS1:** Iluminación tenue analógica, monitores CRT con scanlines, cortes de energía y lluvia de meteoritos.
- **Sigilo Táctico:** Vista en primera persona, linterna 3D que sigue la mirada del jugador, armarios interactivos, medidor de oxígeno y crafteo en tiempo real (Minas PEM, Bombas de Humo y Botiquines).
- **IA de Tripulación:** Alienígenas humanoides con rutinas de trabajo, descanso y patrullaje, con niveles de sospecha individualizados.

## 🚀 Inicio Rápido

### Requisitos
- [Roblox Studio](https://www.roblox.com/create)
- [Rojo](https://rojo.space/) (opcional si solo abres el archivo `.rbxl`)

### Jugar o Editar
1. Clona el repositorio:
   ```bash
   git clone https://github.com/Aguxcraft27/Juego-Astronauta.git
   ```
2. Abre directamente `Astronauta.rbxl` en **Roblox Studio** y presiona **Play (F5)**.

### Compilar desde el código fuente
Para recompilar el place tras editar los archivos `.luau`:
```bash
Scripts\BuildRobloxPlace.bat
```
