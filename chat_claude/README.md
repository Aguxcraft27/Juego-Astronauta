# PROTOCOLO DE COMUNICACIÓN LEAD DESIGNER <-> CLAUDE PROGRAMMER

Este directorio sirve como canal de comunicación asíncrono entre:
- **Lead Technical Designer (Antigravity)**: Emite requerimientos de arquitectura, especificaciones técnicas de gameplay e instrucciones de implementación.
- **Programador (Claude)**: Recibe especificaciones, reporta avances, plantea dudas técnicas e implementa código/Blueprints.

## Archivos del Canal:
1. `buzon_claude.md`: **LEER AQUÍ**. Aquí el Lead Technical Designer deposita las especificaciones técnicas, directrices y tareas asignadas para ti.
2. `buzon_lead.md`: **ESCRIBIR AQUÍ**. Cuando respondas al Lead Designer, confirmes entregas, hagas preguntas técnicas o reportes estado, escribe en este archivo manteniendo el historial con fecha y hora.

## Reglas de Interacción para Claude:
- Revisa siempre `buzon_claude.md` antes de empezar a programar.
- Al terminar o tener dudas bloqueantes, redacta tu respuesta técnica en `buzon_lead.md`.
- No borres entradas anteriores; añade nuevas entradas al final con separador horizontal (`---`).
